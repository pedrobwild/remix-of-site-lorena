# Bewild — project rules

- Use TanStack Start v1 routing and per-route SSR head metadata; keep the legacy navigation bridge because callers rely on it.
- Use bun with the standalone Vitest configuration; CI owns the mandatory type verification because Vite does not typecheck.
- Keep Tailwind v4 configuration and the existing token-based design system; do not replace the application architecture.
- With package sideEffects disabled, import and invoke an exported value for TypeScript module effects; bare side-effect imports are removed in production.
- Subdirectories have their own AGENTS.md. Read src/AGENTS.md before changing application source and src/lib/AGENTS.md or src/guia/AGENTS.md for their scoped rules. Detailed SSR, SEO, sitemap, tracking, content, caching and stylesheet rules moved to src/AGENTS.md without deletion.
- Sitemap edits outside src must also follow the sitemap and video registration rules in src/AGENTS.md, because both generators must match the routes.
