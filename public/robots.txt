# Um único grupo vale para todos os robôs de busca e de IA (Googlebot,
# Bingbot, GPTBot, ClaudeBot, PerplexityBot…). Pela RFC 9309, o robô segue
# SÓ o grupo mais específico que casar com o nome dele: um grupo
# "User-agent: Googlebot" com apenas "Allow: /" fazia o Googlebot ignorar
# todos os Disallow abaixo. Por isso não há grupos por robô, exceto o de
# bloqueio total no fim. Robôs de IA seguem permitidos (citação da marca).

Disallow: /admin/
Disallow: /gpt-knowledge/

Disallow: /mockups/
# URLs com parâmetros de campanha (utm_, gclid, fbclid…) NÃO são bloqueadas
# de propósito (30/09/2026): todas as páginas emitem canonical absoluto sem
# parâmetros, e o Google só consolida a URL se conseguir rastreá-la e ler o
# canonical. Bloquear impedia isso e deixava as variantes "indexadas sem
# conteúdo" quando chegavam por link externo.
